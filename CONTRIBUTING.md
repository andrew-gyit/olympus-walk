# Contribuir a Olympus Walk

Este proyecto es un prototipo educativo en evolución. Reporta errores con navegador, sistema operativo, pasos para reproducirlos, resultado esperado y resultado observado. Evita incluir datos personales, claves o rutas privadas en capturas y registros.

Para contribuir: crea una rama, ejecuta `npm install`, `npm run typecheck`, `npm run build`, `npm run check:structure` y comprueba manualmente el flujo de la primera misión. Separa los datos reales de los derivados y simulados; no presentas ciencia ficticia como datos NASA. Si agregas assets, documenta licencia, procedencia y atribución en `docs/implementation/10-assets-y-licencias.md`.

Las nuevas funcionalidades deben poder vincularse a archivos concretos, pruebas y resultados. No se aceptan afirmaciones de características implementadas únicamente por su aparición en el prompt maestro.
