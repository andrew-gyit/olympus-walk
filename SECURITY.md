# Seguridad y privacidad

Este simulador guarda datos de progreso en `localStorage` del navegador. No utiliza cuentas ni un servidor de usuario en la implementación recuperada. No introduzcas secretos ni tokens reales en el código web: cualquier clave enviada al navegador puede ser inspeccionada.

No adjuntes exports completos de sesiones de OpenCode sin revisarlos: pueden contener rutas privadas, nombres de usuario del equipo, registros de depuración o tokens. El repositorio distribuye un **resumen saneado**, no el historial original de 7 MB. Para reportar un problema de seguridad, contacta con los responsables del repositorio mediante un canal privado y evita publicarlo en un issue abierto.
