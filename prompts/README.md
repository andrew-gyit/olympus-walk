# Prompts y papel de la inteligencia artificial

- `01-master-prompt-videojuego.md`: solicitud extensa original para transformar la idea Olympus Walk en un videojuego de exploración 3D. Es una **especificación**, no evidencia de implementación.
- `02-prompt-documentacion.md`: prompt preparado para que OpenCode auditara el código y completara la documentación. Se conserva como parte del diseño del proceso, no como prueba de que fuera ejecutado.

El proyecto se desarrolló utilizando OpenCode. El historial aportado contiene 425 eventos/mensajes (incluidos 405 mensajes del asistente). Se recuperaron operaciones de escritura y edición de código. Consulta `docs/implementation/02-historia-del-desarrollo.md` para el proceso documentado y `docs/implementation/12-metodologia-de-recuperacion.md` para los límites de la reconstrucción.
