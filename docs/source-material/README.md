# Origen del problema

`olympus-walk-brief-original.pdf` es el documento de referencia entregado con el proyecto. Su contenido describe la problemática de integrar capas científicas marcianas, el perfil de la Dra. Elena Vance, la navegación por pendientes, las rutas, el mapa y cuatro bloques de protección planetaria. La aplicación 3D amplía la solución cartográfica inicial a una experiencia de videojuego.

Antes de publicar este PDF en un repositorio abierto, confirma el permiso de distribución de los titulares, especialmente de imágenes o materiales de terceros incorporados. Si corresponde, elimina el PDF de la versión pública.
