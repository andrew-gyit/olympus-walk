# 9. Development plan

The stages below describe the recommended sequence. They do not imply that any stage has already been completed.

## Stage 1 — First playable 3D slice

Deliver:
- 3D Martian scene.
- Navigable terrain.
- Visible astronaut.
- Third-person camera.
- Keyboard/mouse movement.
- Terrain collision.
- Base camp and landmarks.
- Basic HUD.

**Exit criterion:** a user can start the game, control the astronaut, explore the level, and return to the base.

## Stage 2 — Exploration interactions

Deliver:
- Interaction prompts.
- Inspectable geological objects.
- Scanner.
- Observation records.
- Sample collection.
- Inventory.

**Exit criterion:** a user can approach an object, use an instrument, and see a saved result.

## Stage 3 — Mission and resource simulation

Deliver:
- Mission briefing/objectives.
- Simulation clock.
- Training resource meters.
- Contextual events and alerts.
- Pause/resume.
- Return-to-base objective.
- Mission debrief.

**Exit criterion:** at least one mission can be completed from briefing to debrief.

## Stage 4 — Map and navigation

Deliver:
- Wrist-device/map overlay.
- Player position and heading.
- Points of interest.
- Layer toggles.
- Route alternatives.
- Hazard/precaution overlays.

**Exit criterion:** map state corresponds to the 3D world and the player can navigate using it.

## Stage 5 — Planetary protection

Deliver:
- Precaution categories.
- Training zones.
- Contextual warnings.
- Educational information panel.
- Mission log of player decisions.

**Exit criterion:** the player can recognise and respond to at least one precaution scenario.

## Stage 6 — Additional missions and polish

Deliver:
- Additional scenarios.
- Better models and animations.
- Sound design.
- Visual polish.
- Performance improvements.
- Touch controls if in scope.

## Stage 7 — Scientific data integration

Investigate and integrate suitable verified datasets/services. Preserve local simulation mode and display provenance. Do not let external-data work block the core playable slice.

## Prioritisation rule

Do not prioritise cosmetic dashboards, advanced menus, or high-cost graphics over the core player loop. A controllable astronaut exploring a consistent world is the first milestone.
